# 예시 입력의 기대 결과

`내_제도_입력_예시.csv`를 대시보드의 **제도 지도 → 내 제도 추가** 칸에 붙여넣거나 파일로 고르면 다음과 같이 보여야 합니다.

## 입력 형식

열 10개, 첫 줄은 머리글입니다.

| 열 | 뜻 | 받아들이는 값 |
|---|---|---|
| name | 제도 이름 | 자유 |
| owner | 소관 기관 | 자유 |
| role | 이 연구에서의 구분 | 정량 비교 / 제도 소개 / 병행 사례 |
| plain | 한 줄 설명 | 자유 |
| standard_family | 참조 표준 계열 | `adoption_rules.json`의 standard_families 9종 가운데 하나 |
| standard_detail | 표준 세부 이름 | 자유 |
| form | 채택 형태 | `adoption_rules.json`의 forms 8종 가운데 하나 |
| confidence | 확인 수준 | 확인 / 추정 / 기획안 / 2차 |
| domestic_addition | 국내 추가 항목 | 자유(비워도 됨) |
| basis | 근거 | 자유 |

## 기대 결과

1. **제도 지도** 화면의 카드가 9개에서 11개로 늘고, 추가된 두 카드에는 "내 입력" 배지가 붙습니다. 카드 내용은 입력한 plain·owner·basis만 보이고, 비어 있는 칸(시험 항목 등)은 "입력 없음"으로 표시됩니다.
2. **표준 채택 매트릭스**에 두 행이 추가됩니다.
   - "(예시) 자동차 SW 기능안전 평가" 행은 `(참조 표준 없음)` 열에 "수정 채택" 색으로 칠해지고, 배지는 "추정"입니다.
   - "(예시) 의료기기 SW 밸리데이션" 행은 `ISO/IEC 12207` 열에 "참조" 색으로 칠해지고, 배지는 "기획안"입니다.
3. 매트릭스 아래 **채택 형태 분포** 막대에서 "수정 채택"과 "참조"가 각각 1씩 늘어납니다.
4. **내보내기(CSV)** 를 누르면 원래 13행에 입력 2행이 더해진 15행 CSV가 내려받아집니다.
5. form이나 standard_family에 기준 파일에 없는 값을 넣으면 그 행은 건너뛰고 화면에 "기준에 없는 값: …"이라고 알립니다. (손 검산: form을 "그냥 채택"으로 바꿔 넣어 보기)
6. 입력은 브라우저 안에서만 유지되고 저장소 파일은 바뀌지 않습니다. 새로고침하면 사라집니다.

## 손 검산 포인트 (리뷰어용)

- 예시 2행 모두 `confidence`가 확인이 아니므로, 추가 뒤 매트릭스 머리글의 "확인 비율"이 13행 기준 10/13(77%)에서 15행 기준 10/15(67%)로 내려가야 합니다.
- `adoption.csv`의 확인 10행: 코딩규칙, 취약점, 메트릭·동적시험, 행안부, KCMVP, CC 국제용, CC 국내용, 보안기능확인서, GS, DQ마크. 추정 2행(12207, K-RMF), 기획안 1행(DO-178C).
