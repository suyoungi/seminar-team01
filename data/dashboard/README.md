# data/dashboard — 제도·정책 대시보드의 데이터 파일 (팀원 A)

`dashboard.html`(제도·정책 분석 대시보드)이 읽는 파일입니다. 화면에 보이는 글과 숫자는 모두 이 폴더의 파일에서 옵니다. 내용이 바뀌면 HTML이 아니라 여기 파일만 고칩니다.

| 파일 | 내용 | 원본 | 화면 |
|---|---|---|---|
| `institutions.json` | 제도 9개 카드(근거·소관·대상·시험 항목·참조 표준·채택 형태·상호인정)와 제·개정 연표 | briefing.html 3장, docs/A2 | 제도 지도 |
| `adoption.csv` | 제도 × 참조 표준 × 채택 형태(13행) | briefing.html 4장 표 | 표준 채택 매트릭스 |

| `stakeholders.json` | 이해관계자 10곳의 역할(확인)과 관심·영향·권한(추정) | briefing.html 6장 | 이해관계자 |

겹침 숫자(공통 33, Jaccard 0.46 등)는 이 폴더에 없습니다. 대시보드는 B의 결과 파일 `data/cwe/v4.20/overlap_*.csv`를 그대로 읽습니다. 팀 저장소에 그 파일이 아직 없으면 B의 배포 페이지(minkwanchoi.github.io/seminar-team01)에서 같은 경로를 읽고, 화면에 "B 페이지에서 읽음"이라고 표시합니다.

## 표기 규칙

본문 안의 `[확인]` `[2차]` `[추정]` `[확인 필요]` `[기획안]`은 원문(briefing.html, docs)의 표기를 그대로 옮긴 것입니다. 대시보드가 이 글자를 배지로 바꿔 보여 줍니다.

- **확인**: 법령·고시 조문이나 기관 문서 원문을 직접 읽음
- **2차**: 기사·해설·요약으로만 확인
- **추정**: 자료 없이 세운 판단
- **확인 필요**: 원문을 아직 구하지 못함
- **기획안**: 기획안에만 있고 원문 미확인

## 수업 조건과의 대응 (강의안 39쪽)

| 조건 | 이 대시보드에서 |
|---|---|
| 내 자료를 넣는 입력(붙여넣기·CSV) | 제도 지도·매트릭스의 "내 제도 추가": `examples/내_제도_입력_예시.csv` 형식을 붙여넣거나 파일 선택 |
| 처리 기준은 별도 파일 | `adoption_rules.json`(채택 형태 분류), `proposals.json`의 `criteria`(제언 평가 기준), `limits.json`의 `legend`(표기 규칙) |
| 표·그래프 + 내보내기 | 화면마다 SVG 그래프, 매트릭스·제언 표·물어보기 답을 CSV/마크다운으로 내보내기 |
| 예시 입력과 기대 결과를 저장소에 | `examples/` |
| 서버 없음 · 도구 안 AI 없음 · API 키 없음 | 정적 HTML + JSON/CSV. 물어보기는 준비된 답과 데이터 계산만 |
| 개인정보 없음 | 기관·제도·조문만 다룸 |

## AI 활용 고지

파일 내용은 briefing.html과 docs 문서(팀원 A가 원문 대조를 마친 것)에서 옮겼고, JSON/CSV로 옮기는 작업과 용어 풀이·물어보기 초안은 Claude Code가 1차 작성, 팀원 A가 검토했습니다.
